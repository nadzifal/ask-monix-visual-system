# Screen Contract — Angle

## Question

> Angle mana berubah, dan bentuknya apa?

## Overview = relationship field

Primary reading:

**Output → Hasil**

Patterns:

- output ↑ + result ↓
- output ↓ + result stable
- output stable + result ↓
- output ↑ + result ↑

The relationship itself should be the visual structure.

## Selected Angle = inspect

Reveal:

- Total Konten + delta
- Impressions + delta
- Total FYP + delta
- FYP Rate + pp
- Impression / Konten + delta
- allocation-state boundary
- Creator × Account preview

## Magnitude principle

Overview can compress.

Detail cannot lose magnitude.

Example:

- Total Konten 118 · ↑18%
- Impressions 342 ribu · ↓14%
- Total FYP 7 · ↓12,5%
- FYP Rate 5,93% · ↓2,07 pp
- Impression/Konten 2.898 · ↓27,1%

## Allocation boundary

If explicit allocation plan does not exist:

- describe volume
- do not infer "kurang dikerjakan"
- do not judge adherence
