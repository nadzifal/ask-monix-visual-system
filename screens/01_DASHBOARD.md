# Screen Contract — Dashboard

See also [composition/02_DASHBOARD_LOCKED.md](../composition/02_DASHBOARD_LOCKED.md).

## First viewport

Must contain one dominant reading:

**business condition + human-language interpretation**

Then immediately:

- core metric family
- support metric strip

The user should not need to scan multiple equal-weight cards to understand the brand.

## Example reading

> Performance melemah meski jumlah konten meningkat. Impressions dan FYP Rate belum mengikuti kenaikan konten.

This is descriptive, not causal.

## Visual hierarchy

- Impressions may be subtly stronger
- core metrics share one family
- support metrics are visibly secondary
- Trend is the central visual
- Attention follows Trend
- Operational State is a compact bridge, not KPI block
