# Screen Contract — PIC

## Question

> Area PIC mana paling berubah?

## Overview = scan

Group semantically:

- Menguat
- Relatif stabil
- Melemah

Each PIC shows only:

- outcome movement
- output movement
- result-per-content movement

Example:

`FEREN ↓22,4%`

`Output ↓8,0% · Hasil/konten ↓15,6%`

Do not show the complete metric set in scan state.

## Selected PIC = inspect

Reveal:

- Total Konten + delta
- Impressions + delta
- Total FYP + delta
- FYP Rate + pp
- Impression / Konten + delta
- optional Active Creator
- human interpretation
- evidence boundary
- next Angle investigation

## Guardrail

PIC decomposition is localization, not blame or causal attribution.
