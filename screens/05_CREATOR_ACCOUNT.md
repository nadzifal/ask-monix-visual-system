# Screen Contract — Creator × Account

## Question

> Siapa yang menjalankan angle ini, di account mana, dan perubahan performance paling terlihat di kombinasi mana?

## Analytical unit

**Creator × Account × Angle**

## Overview = execution map

Use:

- creator axis
- account axis
- meaningful intersections
- one primary signal per combination

The map should make it visually obvious whether a pattern is:

- account-localized
- creator-localized
- broad
- concentrated

## Selected combination = inspect

Reveal:

- Total Konten
- Impressions
- Total FYP
- FYP Rate
- Impression / Konten
- current account load
- historical observed range
- recent trend
- evidence strength
- evidence-bounded management move

## Boundary

Observed stable range is not automatically a safe limit.

Best historical account does not automatically deserve more volume.

Localization is not causality.
