## Locked visual character

PIC must remain:

- calm
- beautiful
- immediately readable
- visually decomposed rather than list-like
- data-dense without feeling administrative
- refined and product-native
- consistent with the locked Dashboard visual DNA

## Important analytical rule

PIC is a **localization/decomposition surface**.

It must help answer:

> "Area PIC mana paling berubah?"

It must not imply:

- ranking as judgment
- blame
- causality

The wording and visual hierarchy must preserve:

> **Localization ≠ causality.**

## Change control

Do not:

- redesign PIC into a generic dashboard
- flatten it into a plain list
- replace the decomposition field with ranking cards
- remove the selected-PIC inspect state
- remove the evidence-boundary treatment
- change the visual DNA independently from the locked Dashboard north star

Any future change to this composition requires explicit product-owner approval.

Default implementation instruction:

> **Match the approved PIC north star. Do not redesign it.**
