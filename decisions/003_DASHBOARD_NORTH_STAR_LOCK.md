# North Star Lock — Dashboard

Status: **LOCKED / DO NOT REINTERPRET**

Date locked: 19 September 2026

The approved Ask Monix Dashboard north star is now fixed.

## Approved references

Two approved compositions define the Dashboard visual direction:

1. **Desktop Dashboard North Star**
2. **Mobile Dashboard North Star**

These are the visual target for implementation.

Do not redesign, reinterpret, or "improve" their overall composition without explicit product-owner approval.

## Locked visual character

- calm
- beautiful
- immediately readable
- refined rather than decorative
- strong visual hierarchy
- functional iconography
- warm-white canvas
- deep ink
- botanical green
- restrained semantic red / amber
- elegant spacing rhythm
- light surfaces
- minimal shadow
- no visual spectacle
- no generic SaaS/admin feel

## Locked Dashboard reading

The Dashboard must answer, at a glance:

> **White Inc lagi gimana?**

The approved composition communicates:

1. brand + period context
2. brand condition
3. concise human-language interpretation
4. primary outcome/output metrics
5. supporting metrics
6. performance movement
7. management attention
8. operational condition
9. investigation direction

## Locked mobile order

The mobile order is specifically locked as:

1. Header / brand / period
2. Brand condition
3. **Total Konten + Impressions**
4. **Total FYP + FYP Rate + Impression / Konten**
5. Performance Trend
6. Perlu diperhatikan
7. Kondisi operasional
8. Investigation actions / navigation

Important: **Total FYP, FYP Rate, and Impression / Konten stay directly below Total Konten + Impressions and ABOVE the performance trend.**

Do not move this row below the trend unless explicitly instructed later.

## Locked desktop behavior

Desktop retains the same visual language and information hierarchy, adapted to the wider canvas.

Desktop should not become a different visual system from mobile.

## Why this direction is locked

This direction succeeds because the user can simultaneously perceive:

- the current brand condition,
- the key performance relationship,
- the management concerns,
- the operational condition,

without needing to read a report first.

It balances:

**Visual Craft + Glanceability + Readability + Product Identity**

## Change control

Any future change that alters:

- first-view hierarchy
- brand-state treatment
- metric order
- visual language
- icon language
- overall composition
- management attention / operational condition pairing

must be treated as a deliberate design change, not an implementation cleanup.

Default behavior for implementation agents:

> **Match the north star. Do not redesign it.**
