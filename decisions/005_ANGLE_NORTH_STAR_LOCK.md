## Locked analytical identity

Core question:

> **Angle mana berubah, dan bagaimana hubungan Output → Hasil-nya?**

Angle is a **relationship surface**, not a generic dashboard.

The signature visual grammar is:

**Output → Hasil**

The eye should be able to distinguish patterns such as:
- Output ↑ / Hasil ↓
- Output ↓ / Hasil ↓
- Output stabil / Hasil ↓
- Output ↑ / Hasil ↑

before reading the explanatory sentence.
