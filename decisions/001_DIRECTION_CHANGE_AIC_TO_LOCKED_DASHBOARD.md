# Decision 001 — Dashboard is Locked

## Context

Ask Monix was previously explored as an Adaptive Intelligence Canvas (AIC): a highly adaptive surface whose layout could change based on the intelligence being presented.

That exploration produced useful principles, but the assembled product started to feel unstable and too easy to reinterpret.

The current direction changes that.

## Decision

**Dashboard is a fixed product surface.**

Its structure, hierarchy, and reading path are deliberate and stable.

Dashboard must answer:

> Begitu melihat Dashboard, user langsung tahu brand-nya sedang kenapa dan langsung tahu cara menelusurinya.

Locked reading path:

**Scope → Kondisi brand → Angka → Pergerakan → Yang perlu ditelusuri → Yang sedang dikerjakan**

## What happens to AIC

AIC is not deleted as an intelligence concept.

Useful AIC principles remain:

- one dominant message
- progressive disclosure
- evidence filtering
- reading-path discipline
- complexity is the system's burden

But AIC is **not the visual layout engine for Dashboard**.

## Investigation

Investigation is not a second fixed dashboard.

It is one workspace with different spatial forms based on the analytical question:

- History = temporal narrative
- PIC = decomposition field
- Angle = relationship field
- Creator × Account = execution map

This is **structured-adaptive**, not free-form.

## Hard rule

> Dashboard is locked. Investigation adapts by analytical form. Neither is a free-form AIC canvas.
