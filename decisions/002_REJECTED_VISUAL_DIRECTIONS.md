# Decision 002 — Rejected Visual Directions

These directions were explored and explicitly rejected.

They must not silently return during implementation.

## Rejected: rigid BI wizard

Symptoms:

- large numbered tabs for each investigation stage
- same skeleton repeated across History/PIC/Angle/Creator×Account
- KPI strip at the top of every stage
- large boxed Next Investigation panel repeated everywhere
- excessive dividers and card grids

Reason:

The logic may be correct, but the product feels like a rigid dashboard workflow rather than intelligence unfolding.

## Rejected: editorial/lifestyle reinterpretation

Symptoms:

- serif display headlines
- decorative leaves / botanical illustrations inside product UI
- ornamental slogans
- lifestyle-poster composition

Reason:

This drifted away from the approved clean product-native moodboard.

Moodboard imagery may inspire tone, but decorative imagery is not part of the product UI language.

## Rejected: cinematic/neon legacy UI

Symptoms:

- near-black background
- cyan/violet/pink neon
- glow shadows
- decorative mountains / constellations
- generic "Performance Intelligence" hero

Reason:

It competes with analytical meaning and conflicts with the current Calm Modern Intelligence Workspace.

## Rejected: card-first system

Symptoms:

- every metric in a card
- every section in a card
- border around every group
- multiple equal-weight surfaces

Reason:

The component library begins to dictate information hierarchy.

## Rule

When there is uncertainty, prefer the simpler treatment that preserves the analytical relationship.
