# North Star Lock — History Investigation

Status: **LOCKED / DO NOT REINTERPRET**

Date locked: 19 September 2026

The approved Ask Monix History visual direction is fixed for desktop and mobile.

## Approved references

- Desktop History Investigation North Star
- Mobile History Investigation North Star

These are implementation targets.

## Locked analytical identity

Core question:

> **Ini baru terjadi atau sudah menjadi pola?**

History is a **temporal narrative**.

The eye should perceive the movement through time before reading every label.

## Locked composition

- Ask Monix shell and visual DNA
- brand + period controls
- History context
- analytical headline
- matched historical windows
- strong temporal trajectory / performance journey
- absolute values and state per period
- visible onset / persistence / recovery or deterioration
- output → result relationship where useful
- concise “Apa yang terlihat” interpretation
- explicit evidence boundary
- contextual next investigation into PIC
- mobile version preserving the same narrative in a vertical reading path

## Visual character

History must remain:
- calm
- beautiful
- temporal
- elegant
- readable at a glance
- narrative rather than dashboard-like
- consistent with the locked Ask Monix visual DNA

## Hard rules

Do not:
- turn History into four KPI cards
- use a generic chart dropped into a card with no narrative structure
- imply causality from temporal pattern
- remove matched-window comparability
- flatten the temporal journey into text only

History may establish:
- onset
- persistence
- recovery / deterioration

History does not prove:
- root cause

## Change control

Any future change to the temporal composition requires explicit product-owner approval.

Default implementation instruction:

> **Match the approved History north star. Do not redesign it.**
