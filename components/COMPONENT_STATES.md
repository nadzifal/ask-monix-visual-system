# Component & State Contract

## Analytical headline

States:

- positive
- negative
- mixed
- informational / insufficient evidence

Structure:

1. semantic accent rail
2. key claim
3. optional selective semantic color
4. supporting sentence

## Metric

Detail metric supports:

- label
- absolute current value
- comparator delta
- semantic business meaning

Rules:

- FYP Rate change uses percentage points
- Active Creator change uses absolute count

## Focus state

Focus should be obvious but restrained:

- slight tint
- local outline or rail
- semantic accent
- no heavy shadow

## Unknown / insufficient evidence

Use neutral treatment.

State what is missing:

- allocation plan unavailable
- incomplete account mapping
- immature observation window
- sample too thin

Unknown must not silently become "stable."

## Hover / selected / expanded

Hover:

- subtle background/border shift

Selected:

- clear focus tint/accent
- preserve nearby context

Expanded:

- reveal magnitude and deeper evidence in place
- do not reset scope

## Chart

- minimal grid
- thin line
- one y-axis
- raw values accessible
- no decorative charting
- no three y-axes

## Status

Do not turn every entity into a traffic-light dashboard.
