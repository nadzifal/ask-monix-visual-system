# Moodboard V1 — Approved Visual Direction

## Product feel

**Calm intelligence for faster decisions.**

The visual goal is not to make data look beautiful.

The goal is to make intelligence easy to perceive.

## Personality

- analytical
- calm
- focused
- trustworthy
- actionable
- human-centered
- modern without visual noise

## Visual anchors

### Canvas
Crisp warm-white, not beige and not gray-heavy.

### Typography
Clean modern sans-serif. Strong legibility. No serif display type.

### Primary color
Botanical green, used with restraint.

### Semantic colors
- green = strengthening / positive business meaning
- red = weakening / concern
- amber = mixed / uncertain
- gray = neutral / unknown / insufficient evidence

### Surfaces
Open canvas by default. Cards only when interaction or grouping earns them.

### Lines
Local, thin, functional. Never a grid of separators for its own sake.

### Shadow
Almost none.

### Rhythm
Quiet areas must exist. Not every element should call for attention.

## Product motto

> Less reading to understand more.

## Do

- use active whitespace
- combine number + human sentence
- preserve magnitude in detail
- let relationships become structure
- keep one dominant message
- use color semantically
- make navigation preserve analytical context

## Don't

- over-card the interface
- use decorative charts
- use serif headlines
- use botanical/lifestyle illustration
- treat every section as a panel
- make every metric equally loud
- let a component library dictate page composition
