# Responsive Rules

> Same intelligence. Adaptive presentation.

Do not remove analytical meaning on smaller screens.

## Desktop

- preserve full investigation composition
- one dominant message per viewport
- side context only when useful
- execution map may use 2D relationships

## Tablet

- collapse secondary context
- preserve headline + evidence relationship
- reduce simultaneous columns
- detail may appear under selected scan item

## Mobile

Single-column reading path:

1. primary answer
2. strongest evidence
3. interpretation
4. deeper detail
5. next move

Rules:

- comfortable touch target around 44px
- Reasoning Trail may scroll/compact
- metric groups may become 2-column or stacked
- execution map becomes creator sections with account items
- charts remain readable
- supporting evidence may progressively disclose
- absolute values remain visible

Mobile must not become a different product.
