# Composition Grammar

## Core rule

> Reasoning determines layout. Component library only supports it.

## Investigation reasoning contract

Every stage answers:

1. Apa yang berubah?
2. Di mana paling terlihat?
3. Apa yang belum diketahui?
4. Ke mana telusur berikutnya?

The spatial composition should reflect that reasoning.

## Persistent shell

Keep only:

- product shell
- current scope
- lightweight Reasoning Trail
- filter access

Do not persist large numbered stage tabs.

Bad:

`1 Dashboard | 2 History | 3 PIC | 4 Angle | 5 Creator × Account`

Good:

`White Inc → Performance melemah → Feren → Angle A → Creator × Account`

## Scan vs inspect

Scan surface:

- low information density
- enough to locate a pattern
- not the complete KPI set

Inspect surface:

- absolute value
- comparator delta
- interpretation
- evidence state
- supporting context

## Magnitude rule

Detail must preserve absolute magnitude + change.

Example:

`118 konten · ↑18%`

`342 ribu impressions · ↓14%`

Do not stop at:

`↑18% → ↓14%`

## Next move

Do not repeat the same large green "Next Investigation" panel on every stage.

The next move can be:

- inline directional cue
- contextual action
- local button attached to evidence

## Containers

Default hierarchy:

1. whitespace
2. typography
3. alignment
4. local separator
5. container only when needed
