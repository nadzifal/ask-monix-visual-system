# Performance Investigation Workspace

Investigation is **one workspace**, not four disconnected products.

## Persistent state

The workspace should preserve:

- brand
- period
- comparator
- active concern
- selected PIC
- selected Angle
- selected Creator × Account
- Reasoning Trail
- back-state

## Reasoning Trail

This is not decoration.

It records how the user arrived at the current analytical state.

Example:

`White Inc → Performance melemah → Feren → Angle A → Creator × Account`

Clicking a previous node or Back should restore prior context rather than resetting to defaults.

## Stage-specific visual forms

### History
Temporal narrative.

### PIC
Decomposition field.

### Angle
Relationship field.

### Creator × Account
Execution map.

## What must not happen

Do not reuse one page skeleton like:

scope → stage tab → headline → KPI strip → card → next box

for every stage.

That recreates a BI wizard.

## Evidence discipline

- localization ≠ causality
- execution ≠ performance
- unknown stays unknown
- recommendation ≠ final decision
- observed stable range ≠ safe limit
- best historical account ≠ automatic allocation recommendation
