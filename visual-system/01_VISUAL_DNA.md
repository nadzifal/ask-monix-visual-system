# Visual DNA

## Typography

Primary family: **Inter or Geist-class sans-serif**.

No serif display typography.

### Headline grammar

Pattern:

**semantic accent rail → bold key claim → selective semantic color → lighter supporting sentence**

Rules:

- sentence case
- never ALL CAPS for main headline
- main claim 1–2 lines
- support 1–2 lines
- color only one important phrase/value when useful
- never color the whole headline

Semantic rail:

- red = weakening / concern
- green = strengthening
- amber = mixed / uncertain
- neutral = informational / insufficient evidence

## Surface language

Default = **open canvas**.

A card/surface is earned only when it:

- groups one interaction
- establishes a focus state
- contains compact dense content
- communicates a meaningful state

Prefer:

- whitespace
- alignment
- scale
- local hairlines

over:

- repeated bordered cards
- full-width section boxes
- dense divider grids

## Color language

Arrow = what numerically happened.

Color = what that movement means for the business outcome.

An upward output delta can still be red when results worsen.

## Whitespace

Whitespace is active structure.

It should:

- establish hierarchy
- separate narrative beats
- create visual rest
- reduce competition

It should not create dead empty zones.

## Modernity

A screen is modern when:

- state becomes structure
- relationships become structure
- the user reads less but understands more
- interaction preserves context
- components exist because they help reasoning
