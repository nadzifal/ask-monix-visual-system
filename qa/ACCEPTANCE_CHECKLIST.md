# Visual Acceptance Checklist

A screen fails if any hard-fail condition is present.

## Visual DNA

- [ ] Inter / Geist-class sans-serif
- [ ] No serif display text
- [ ] No decorative botanical/lifestyle illustration
- [ ] Warm-white crisp canvas
- [ ] Deep ink primary text
- [ ] Botanical green restrained
- [ ] Red/amber semantic, not decorative
- [ ] Minimal shadow
- [ ] Borders local, not everywhere

## Headline

- [ ] One dominant analytical message
- [ ] Sentence case
- [ ] Semantic accent rail
- [ ] Selective color only
- [ ] Supporting sentence concise

## Composition

- [ ] Dashboard follows locked reading path
- [ ] Investigation body changes by analytical form
- [ ] No repeated investigation skeleton
- [ ] No large numbered stage tabs
- [ ] Reasoning Trail preserves path
- [ ] Scan ≠ inspect
- [ ] Whitespace creates hierarchy
- [ ] Containers are earned

## Data presentation

- [ ] Detail shows absolute value
- [ ] Detail shows comparator delta
- [ ] FYP visible where relevant
- [ ] FYP Rate visible where relevant
- [ ] FYP Rate delta uses pp
- [ ] Interpretation explains relationships

## Evidence integrity

- [ ] Localization is not presented as causality
- [ ] Unknown evidence is explicit
- [ ] No safe limit without validation
- [ ] Recommendation is evidence-bounded
- [ ] No ranking/blame without valid contract

## Modernity

- [ ] Feels like an intelligence workspace
- [ ] Relationships become structure
- [ ] Less reading to understand more
- [ ] Interaction preserves context
- [ ] No decorative-only components
